# TypeScript Hexagonal Template

## 🤔 ¿Que es TypeScritp Hexagonal Template?

TypeScritp Hexagonal Template es una template simplificada basada en la [template](https://github.com/CodelyTV/typescript-basic-skeleton) y en los cursos de la gente de [CodelyTv](https://codely.com/) sobre DDD y Arquitectura Hexagonal.

Esta template esta pensada para desarrollar una aplicacion web completa, con una servidor backend como API, una aplicacion frontend para poder consumirla la API.
